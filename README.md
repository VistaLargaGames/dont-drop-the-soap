# Don't Drop the Soap!

A comedy, fully steam-censored prison-shower pickup minigame. You dropped the soap. Hold to bend over and grab it, but don't finish bending with anyone standing behind you.

**[Play it in your browser](https://vistalargagames.github.io/dont-drop-the-soap/)** (PC or phone, landscape)

- **PC:** hold SPACE or the mouse button to bend, let go to stand back up
- **Phone:** hold anywhere on the screen

Made with Godot 4.
